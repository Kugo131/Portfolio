# Проекты

|---|---|---|
| [**Cookie Cats — A/B Test & Player Behavior Analysis**](https://github.com/Kugo131/cookie-cats-ab-test-analysis) | Анализ A/B-теста мобильной игры Cookie Cats: оценка влияния переноса игрового ограничения с 30-го на 40-й уровень на Retention D1 и D7. Проверка статистической значимости, расчет доверительных интервалов, сегментация игроков по активности. SQL-анализ с использованием CTE и оконных функций.
